# Dropshot distribution

The public site introduces Dropshot and provides access to published app downloads.

## Language

**Dropshot**:
The macOS menu bar app that converts a dragged HEIC image into clipboard-ready JPEG or PNG image content.

**Drop Zone**:
The temporary target beneath Dropshot’s menu bar icon where a user drops an HEIC image for conversion.

**Download**:
A published installer for Dropshot that a visitor can retrieve from the site.
